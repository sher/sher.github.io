# sher.github.io

Personal blog built with [Astro](https://astro.build) and based on the [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) theme.

## Commands

- `pnpm install` installs the packages.
- `pnpm dev` starts the local server.
- `pnpm build` builds the site into `dist/`.

A push to `master` deploys the site to GitHub Pages with `.github/workflows/deploy.yml`.
